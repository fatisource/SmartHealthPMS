Run the desktop application

Set it up on your computer

The deployed GitHub Pages site is a project landing page. The Java Swing application runs locally and connects to MySQL.

Install prerequisites

Install a Java Development Kit and start MySQL through XAMPP or another local MySQL-compatible server.

Import the case-study database

Import spms_db.sql into MySQL using phpMyAdmin or the MySQL command line.

Compile and launch

On Windows, run run.bat from the project folder. It compiles the Java sources and launches the Swing application.

Database import warning: spms_db.sql drops and recreates the project tables. Importing it replaces existing data in those tables; back up any data you need first.

Publish this landing page with GitHub Pages

After pushing the repository to GitHub:

  1. Open the repository's Settings and select Pages.
  2. Under the build and deployment settings, choose Deploy from a branch.
  3. Select the main branch and /(root), then save.
  4. When deployment finishes, open the Pages URL shown in Settings.
